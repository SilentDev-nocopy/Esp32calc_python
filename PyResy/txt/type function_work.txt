TYPE() FUNCTION WORKING IDEAS

1. What is the "type()" function?
        A built-in function which can be used for type conversion and type querying.

2. How many arguments can the "type()" function have?
        The "type()" function can have exactly 1 argument.

3. What can be given as the argument?
        Only one of the 4 built-in main types:
        int, float, string, bool

4. Can a variant be given directly as the argument?
        No. The argument has to be one of the 4 built-in main types.

5. How is type conversion called?
        By calling ".type()" on the given variant:
        "value.type(type)"

6. Does ".type()" change the original variant?
        No. The original variant's value and type are not changed.
        The ".type()" function returns the value in the requested type.

7. Example:
        v x int = 10
        v y float = 2

        print_cmd(x.type(float))
        print_cmd(y.type(bool))

        output:
        10.0
        true

8. What happens when converting a value to bool?
        If the original value is above 0, the result is true.
        Otherwise the result is false.

9. Does the bool conversion overwrite the original value?
        No. The original variant stays unchanged.

10. Can "type()" be used only for conversion?
        No. It can also be used for type querying.

12. What happens when converting int to float?
        The value is returned as a float.
        Example:
        v x int = 10
        x.type(float) -> 10.0

13. What happens when converting float to int?
        if the value is less then 5 then go to the smaller value. Example: 0.4 -> 0   0.5 -> 1  1.4 -> 1   1.5 -> 2

14. What happens when converting int to string?
        The numbers becomes text. Example: 10 -> "10" ##due to int+string is enabled to print out.

15. What happens when converting float to string?
        Same as with int to string.

16. What happens when converting bool to int?
        true -> 1  false -> 0

17. What happens when converting bool to float?
        same as bool to int but in float format.

18. What happens when converting bool to string?
        true -> "true"  false -> "false"

19. Is string -> int conversion allowed?
        No

20. Is string -> float conversion allowed?
        No

21. Is string -> bool conversion allowed?
        No

22. What happens when a string cannot be converted to the requested type?
        gives error:"{variantname_that_wanted_to-change} Cant convert to {requested type}. Error code:"ConversionFail"

23. What happens if the argument is not one of the 4 built-in main types?
        gives error:"{given argument} is an invalid type. Error code:"TypeError"

24. What happens if "type()" gets 0 arguments?
        gives the "caller" variant's type.

25. What happens if "type()" gets more than 1 argument?
        gives error:"{all given argument} is too much argument. it only receives 1. Error code:"FunctionMultiArgumentError"

26. Can "type()" be called on both variants and constants?
        yes.

27. Does using ".type()" create a new value or modify the original value?
        It returns the converted value and does not modify the original variant.
