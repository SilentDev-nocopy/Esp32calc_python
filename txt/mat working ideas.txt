1. What is the "mat" statement?
        A statement which compares a given value against multiple possible cases.

2. What is the basic syntax of "mat"?
        The synstax looks like this:
        "mat variant_name: <- or if you need the type then on the end, put the .type() function.
            "1": <-string 
                print_cmd("1")
            int: <- type   (only usable if type asked!)
                print_cmd(variant_name, "Is int")
            1:  <- int, float
                print_cmd("1")
            true:
                print_cmd("is true") <- booliant (only usable if type asked!)
3. Can "mat" have an else branch?
        Yes. On the last brach it can have an "else" branch.

4. What happens when a case matches?
        The matching branch runs and then the "mat" ends. There is no fall-through.

5. What happens when no case matches and there is no else?
        The runtime continues after the "mat".

6. What can be used as the value that "mat" checks?
        int, vloat, string, bool and any other type.

7. What can be used as a case value?
        Cases use concrete values.
